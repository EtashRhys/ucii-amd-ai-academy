# Friction Log

Record real friction encountered while learning, provisioning, building, testing, and submitting. Do not invent friction retrospectively.

## Entry template

### YYYY-MM-DD — Short title

**Surface:** AMD AI Developer Program / AMD Developer Cloud / ROCm / Lablab / model runtime / other

**Goal:** What was being attempted?

**Observed friction:** What actually made the task harder, slower, ambiguous, or error-prone?

**Evidence:** Error text, behavior, documentation conflict, or reproducible observation. Do not include secrets.

**Workaround:** What resolved or reduced the issue?

**Impact:** Time, reliability, usability, cost, or project-design consequence.

**Product feedback candidate:** Yes / No

## 2026-09-14 — Developer Cloud credit approval delay disclosed

**Surface:** AMD AI Developer Program / AMD Developer Cloud

**Goal:** Request introductory AMD Developer Cloud credit for AMD-backed project work.

**Observed friction:** AMD's confirmation page stated that Developer Cloud demand is high and credit approvals may be delayed.

**Evidence:** Request confirmation advised an expected activation email after validation and provided a five-business-day escalation path.

**Workaround:** Request submitted early; project will wait for authoritative activation instructions and avoid assuming credit availability.

**Impact:** Infrastructure start date may depend on approval timing.

**Product feedback candidate:** No — currently an explicitly communicated capacity constraint rather than an unexplained failure.
