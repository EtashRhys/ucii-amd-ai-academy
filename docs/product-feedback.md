# Product Feedback

Capture evidence-backed feedback about AMD/Lablab developer surfaces during the Academy program.

## Rules

- Separate bugs from documentation gaps, feature requests, and user preference.
- Include enough context to reproduce or understand the issue.
- Do not include credentials, tokens, private account data, or other secrets.
- Prefer specific actionable feedback over generic praise or complaints.
- Do not create feedback merely because a submission form asks for it.
